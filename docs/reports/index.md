# Munchies Engineering Reports

Welcome to the **Munchies** engineering documentation and project reports hub.

Here you will find reports detailing the software process, architecture, distributed systems design, web services, and advanced modeling for the Munchies platform.

---

## Available Reports

- [**Software Process Engineering (SPE)**](./spe/index.md)  
  Covers the overall project deliverables, domain model, microservices implementation, DevOps pipeline (CI/CD, QA, release automation), deployment, and benchmarks.

- [**Applicazioni e Servizi Web (ASW)**](./asw/index.md)  
  Documentation and report covering web service architectures, APIs, and client-server integration.

- [**Distributed Systems (DS)**](./ds/index.md)  
  Details of the distributed architecture, consistency models, fault tolerance, and inter-service messaging.

- [**Software Architecture And Platforms (SAAP)**](./saap/index.md)  
  Architectural patterns, component diagrams, platform choices, and infrastructural decisions.

- [**Advanced Software Modeling and Development (ASMD)**](./asmd/index.md)  
  Advanced domain modeling, design patterns, and formal models.
