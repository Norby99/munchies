# User Stories

## Requirements Overview

1. **Authentication and Account Management**:
    1. Ability to register to the system.
    2. Ability to log in into the system.
    3. Ability to update user profile.

2. **Restaurant Browsing**:
    1. Ability to browse restaurants and menus.
    2. Ability to view dish details and availability.

3. **Menu Management [Restaurant Staff]**:
    1. Ability to manage dish availability.

4. **Order Management**:
    1. Ability to place a delivery order.
    2. Ability to pay for an order.
    3. Ability to track order status.

5. **Notifications**:
    1. Notification system for order status changes.
    2. Notification system for payment confirmation.

6. **Table Reservations**:
    1. Ability to reserve a table at a restaurant.

---

## User Stories

In order to capture and describe the functional requirements listed before, we have decided to use the User Stories approach.

These user stories are written from the perspective of the end-users and describe the features and functionalities that they expect from the application.

### Authentication and Account Management

1. **User Registration**\
    As a **new user**,\
    I want to register an account,\
    so that I can order food on Munchies.

2. **User Login**\
    As a **registered user**,\
    I want to log in with my credentials,\
    so that I can access the protected features of Munchies.

3. **Update User Profile**\
    As a **registered user**,\
    I want to update my profile,\
    so that my personal data stays up to date.

### Restaurant Browsing

4. **Browse Restaurant Menu**\
    As a **client**,\
    I want to see the restaurants and their menus,\
    so that I can choose what to order.

### Menu Management

5. **Manage Dish Availability [Restaurant Staff]**\
    As a **restaurant staff member**,\
    I want to mark a dish as unavailable,\
    so that clients cannot order food that the kitchen cannot prepare.

### Order Management

6. **Place Order**\
    As an **authenticated client**,\
    I want to place a delivery order,\
    so that I receive my food at home.

7. **Pay Order**\
    As a **client who placed an order**,\
    I want to pay for it,\
    so that the restaurant can start preparing it.

8. **Track Order Status**\
    As an **authenticated client**,\
    I want the status of my order to advance,\
    so that I can follow it until delivery.

### Notifications

9. **Payment Success Notification**\
    As a **client**,\
    I want to be notified when my payment succeeds,\
    so that I know my order is confirmed without checking the app.

### Table Reservations

10. **Reserve a Table**\
    As an **authenticated client**,\
    I want to reserve a table at a restaurant,\
    so that I have a seat when I arrive.
